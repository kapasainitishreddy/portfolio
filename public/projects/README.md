# Project screenshots

Drop a screenshot for any project here, named `<project-id>.jpg` (or .png/.webp),
then set the matching `image` field in `src/data/projects.ts`, for example:

```ts
{ id: "vakya", /* ... */ image: "/projects/vakya.jpg" }
```

Project ids: siraba-hq, vakya, keeply, un-em, smriti-ai, receipts,
pasthour-ai, vibedesk, unsent.

If no image is set, a tasteful generated ink placeholder is shown automatically.
