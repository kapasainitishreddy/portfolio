## CHOSEN APPROACH: Quantum Noir (Approach A)

### Design Movement
Cyberpunk Futurism × Japanese Minimalism — precision geometry meets neon glow

### Core Principles
1. **Dark canvas, luminous accents** — deep blacks and near-blacks as the base, with electric neon highlights that feel like they're actually emitting light
2. **Geometry as decoration** — hexagons, grid lines, circuit traces as structural motifs
3. **Motion as information** — particles, waves, and animations communicate depth and system activity
4. **Layered depth** — multiple translucent planes create a sense of 3D space

### Color Philosophy
- **Background**: `#020408` — near-absolute black with a blue undertone (space-like)
- **Primary neon**: `#00f5ff` — electric cyan, the signature brand color
- **Secondary neon**: `#bf00ff` — deep violet/magenta
- **Accent warm**: `#ff6b35` — ember orange for contrast
- **Text primary**: `#e8f4f8` — cool white
- **Text secondary**: `#6b8fa3` — muted steel blue
- Emotional intent: power, precision, intelligence, mystery

### Layout Paradigm
Asymmetric split layouts — content anchored left, 3D visuals filling right. Navigation as a vertical sidebar on desktop. Sections separated by animated dividers. No centered hero.

### Signature Elements
1. **Hexagonal grid overlay** — subtle hex pattern on backgrounds
2. **Glowing circuit traces** — animated SVG lines connecting elements
3. **Scan-line effect** — subtle horizontal scan animation on hover

### Interaction Philosophy
Every interaction has a physical response: hover states glow, clicks ripple, scroll triggers particle effects. The UI feels alive and reactive.

### Animation
- Three.js particle systems for hero backgrounds
- GSAP-style smooth scroll reveals
- Framer Motion for component transitions (200-400ms)
- Continuous ambient animations (slow particle drift, pulsing glows)
- Theme transitions: full-screen wipe with particle dissolve

### Typography System
- **Display**: `Orbitron` — geometric, futuristic, used for headings
- **Body**: `JetBrains Mono` — monospace, technical, used for body text
- **Accent**: `Space Grotesk` — clean geometric sans for UI labels
- Hierarchy: 72px display → 48px h1 → 32px h2 → 20px h3 → 16px body

### Brand Essence
*For the builder who thinks in systems — a portfolio that proves intelligence through design.*
Adjectives: **Precise**, **Luminous**, **Relentless**

### Brand Voice
Headlines sound like mission briefings. CTAs are commands, not invitations.
- Example headline: "Systems that think. Communication that lands."
- Example CTA: "Initiate Contact" / "Access Projects"

### Wordmark & Logo
A stylized hexagon with a circuit-trace "S" inside — geometric, sharp, glowing cyan on black.

### Signature Brand Color
`#00f5ff` — Electric Cyan — unmistakably this brand's.

## 4 Themes

### Theme 1: CYBERPUNK — Neon Grid
Electric cyan/magenta neon on deep black. Three.js particle field. Hexagonal grid overlays. Circuit trace animations.

### Theme 2: SPACE — Cosmic Void
Deep space with Three.js star field and nebula. Purple/blue/gold palette. Gravitational lensing effects. Floating holographic panels.

### Theme 3: INK — Suminagashi (from original repo)
Fluid ink simulation. Organic flowing forms. Monochrome with copper/gold accents. Calligraphic typography.

### Theme 4: TERMINAL — CLI Interface
Full terminal emulator aesthetic. Green-on-black phosphor. Command-driven navigation. Type commands to navigate sections. Code sidebar with live navigation.
